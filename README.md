# Prize Draw

Open **index.html** in a current browser. The site uses plain HTML, CSS, and JavaScript. No installation or hosting is needed.

Open **Draw settings** with the gear icon on the right of the header. Set the **end number** to define a pool from **1 to your number** (up to 9999). The default is 500. Set **Number of Winners per session** to choose how many draws this session allows; it defaults to the full pool size. Press Enter or click away to apply a number. Press **Start draw** or the space bar to roll a number. Previous winners are always excluded. You can change the spin duration, turn on sound, use fullscreen mode, export the results as CSV, and reset the session. To lower the end number below a winner already drawn, or set the winner target below the number already drawn, reset the session first.

The leftmost rolling digit only shows leading digits possible within the chosen range (0–5 for the default range of 1–500).

The decorative globe rotates slowly and the satellite drifts slightly. A short satellite signal animation lights the number pads before each roll. These animations are skipped when reduced motion is enabled in the browser or operating system.

The winner history is saved in the browser on this device. Export the CSV if you need a copy elsewhere. The interface uses the Tomorrow font from Google Fonts when online and a system font when offline.

The interface keeps its dark theme and uses the purple `#4E2780` sampled from the supplied TSE reference for its main highlights.
